# TrackiMetrix — web

F1 standings, results, the season calendar, driver and team pages, and race replays drawn from real
car telemetry. Live at **https://panithynihal-dev.github.io/F1/**.

Built with React Native for the web (Expo, react-native-web), styled with NativeWind (Tailwind
class names). All data comes from two free public APIs, called straight from the browser:
[OpenF1](https://openf1.org) (sessions, laps, car positions) and
[Jolpica](https://github.com/jolpica/jolpica-f1) (standings, schedule, results). Answers are cached
in the browser, so repeat visits are fast.

## Run it

```sh
npm install
npm start          # dev server at http://localhost:8081
npm run typecheck  # TypeScript: catches type mistakes
npm run lint       # ESLint: catches code mistakes
npm run build      # production build into dist/ (served under /F1)
```

On a low-memory machine build with `npx expo export -p web --max-workers 1`.

## Deploying

Push to `main`. GitHub Actions (`.github/workflows/deploy.yml`) type-checks, lints, builds and
publishes to GitHub Pages; watch it in the repo's **Actions** tab.

## What everything is

### Files in the top folder

| File | What it's for |
| --- | --- |
| `package.json` | The list of libraries the site uses, and the `npm` commands above. |
| `package-lock.json` | Exact library versions, written by npm. Never edit by hand. |
| `app.json` | Expo's settings: site name, icon, colours, and the `/F1` web address prefix. |
| `tailwind.config.js` | **The design system**: colours, fonts, corner radius. Change the look here. |
| `babel.config.js` | Lets `className="..."` styling work on React Native components (NativeWind needs it). Leave alone. |
| `metro.config.js` | Expo's bundler settings: points it at the stylesheet in `src/styles`. Leave alone. |
| `tsconfig.json` | TypeScript settings, including the `@/` shortcut that means "src/". |
| `eslint.config.js` | Rules for `npm run lint`. |
| `nativewind-env.d.ts` | Type hints so TypeScript accepts `className`. Leave alone. |
| `expo-env.d.ts` | Generated by Expo, not in git. Ignore it. |
| `AGENTS.md` | Notes for AI coding assistants working on this repo. |
| `dist/`, `.expo/`, `node_modules/` | Generated folders (build output, caches, libraries). Not in git, safe to delete. |

### Other top folders

| Folder | What's inside |
| --- | --- |
| `assets/brand/` | The logo and the little loading-car drawing. |
| `assets/photos/` | Free-licence photos (Wikimedia Commons) used on the pages. Credits live in `src/data/photos.ts`. |
| `scripts/` | `build-champions.mjs`: run once after each season ends to refresh the list of past champions. |
| `.github/workflows/` | The automatic deploy to GitHub Pages. |

### `src/` — the site itself

```
src/
  app/          The pages. Each file is one web address:
                  index.tsx            → /             (Home)
                  calendar.tsx         → /calendar
                  standings.tsx        → /standings
                  results/[sessionKey] → /results/123  (a race, qualifying, practice)
                  replay/[sessionKey]  → /replay/123
                  drivers/[id]         → /drivers/antonelli
                  teams/[id]           → /teams/mercedes
                  _layout.tsx          wraps every page: fonts, top nav, footer
  components/   The building blocks pages are made of, grouped by where they're used:
                  home/  results/  standings/  replay/  stats/ (driver + team pages)
                  layout/  (page frame, nav, footer)
                  ui/      (buttons, tabs, HelmetText, CreditedImage, loading states…)
                  three/   (the 3D replay view, loaded only on the replay page)
  api/          Talks to OpenF1 and Jolpica: one function per kind of request, plus their types.
  data/         Fetches through the API with caching, and combines answers into what pages need.
                  photos.ts lists every photo and its credit.
  logic/        Pure calculations, no network: dates and time zones, "is the title decided",
                points per round, team colours, helmet colour palettes, replay maths.
  hooks/        Small React helpers: the current time, reduced-motion, driver/team stats.
  styles/       global.css: page-wide CSS (helmet colour animation, carousel progress bar…).
```

A rule of thumb for finding things: **what it looks like** is in `components/`, **what's on a
page** is in `app/`, **where numbers come from** is in `data/` and `api/`, **how they're worked
out** is in `logic/`.

## Handy facts

- Replays load four laps at a time. Links can point at a moment:
  `/replay/<session>?laps=5-8&t=90` opens laps 5–8, ninety seconds in. Keyboard: space to play or
  pause, ← / → to skip ten seconds, + / − to change speed.
- Champions' and winners' names use their helmet colours (`src/logic/helmets.ts`). Add a driver
  there to give them a palette; anyone else gets their team colour.
- To add a photo: save it as WebP in `assets/photos/` and add it, with its credit, to
  `src/data/photos.ts`. Only use free-licence photos and always keep the credit.
